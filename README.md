# Facebook Graph API Automation

A Python-based automation tool for publishing content (text, links, images, and videos) to a Facebook Page using the Meta Graph API (v25.0). 

This project is designed to pull structured post content from local JSON files and randomly select items to post, making it ideal for scheduled content queues. It also features a clever Unicode workaround to support **bold** and *italic* text formatting in Facebook feed posts.

## Features

- **Automated Posting**: Post text, links, photos, and videos directly to a Facebook Page feed.
- **Custom Text Formatting**: Automatically converts designated text to Unicode bold and italic characters to bypass Facebook's standard text limitations.
- **JSON Content Queues**: Reads from `cirucci_posts.json` (for book quotes) and `stdPosts.json` (for standard link posts).
- **Token Management**: Includes a utility function to exchange short-lived Graph API tokens for long-lived ones.
- **Logging**: Utilizes `loguru` for robust, rotating log management (`facebook_automation.log`).

## Prerequisites

- Python 3.x
- [pipenv](https://pipenv.pypa.io/en/latest/) for dependency management
- A Meta Developer account with an App configured for the Graph API.
- A **User Access Token**. (The script includes a built-in token management function to easily exchange this for a Page Token, bypassing Facebook's frustrating UI for acquiring Page Tokens directly).

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd facefuck
   ```

2. Install dependencies using pipenv:
   ```bash
   pipenv install
   ```

## Configuration

This project uses `python-dotenv` to manage secrets. You must create a `.env` file in the root directory and populate it with your specific Meta App and Page details.

Create a `.env` file and add the following variables:

```env
PAGE_ID=your_facebook_page_id
FB_ACCESS=your_page_access_token
DEFAULT_MESSAGE=Your default fallback message here
APP_ID=your_meta_app_id
APP_SECRET=your_meta_app_secret
SHORT_LIVED_TOKEN=your_short_lived_user_token_for_exchange
```

*Note: The `SHORT_LIVED_TOKEN`, `APP_ID`, and `APP_SECRET` are primarily used if you need to run the `get_long_utoken()` function to generate a long-lived access token.*

## Usage

Ensure you run the scripts within your pipenv environment:
```bash
pipenv shell
```

### Content Files

The automation relies on two primary JSON files to draw content from:
- `cirucci_posts.json`: Designed for posting book quotes. Expected format includes `book_title`, `text`, `author`, and `purchase_link`.
- `stdPosts.json`: Designed for standard posts. Expected format includes `title`, `text`, and `link`.

### Running the Scripts

**1. Posting Standard Links**
To post a random standard post from `stdPosts.json`:
```bash
python std_post.py
```

**2. Posting Book Quotes**
Currently, `facebook_graph.py` is configured to process the `cirucci_posts.json` file. You can uncomment `post_cirucci()` in the `if __name__ == "__main__":` block of `facebook_graph.py` and run:
```bash
python facebook_graph.py
```

### Media Uploads
If you are developing your own scripts based on this framework, you can import and use the included media functions from `facebook_graph.py`:
- `send_picture(path, caption)`: Uploads an image to the page.
- `send_video(path, description, title)`: Uploads a video to the page.

## Project Structure

- `facebook_graph.py`: The core script containing API logic, text formatting dictionaries, and quote posting logic.
- `std_post.py`: A script specifically for handling and posting standard updates.
- `keytime.py`: Handles the loading and export of environment variables.
- `cirucci_posts.json` / `stdPosts.json`: Data files containing the post content.
- `facebook_automation.log`: The rotating log file generated by `loguru`.
